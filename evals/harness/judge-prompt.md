한국어 사내 문서 두 개를 비교해 읽는다. `{SRC}` 는 원래 초안이고, `{DOC}` 는 그 초안을 다듬은 판이다. 다른 파일은 열지 않는다.

`{DOC}` 를 처음부터 끝까지 읽고 두 가지를 센다.

1. 사람이 쓰지 않았을 것 같은 문장: 한국어 실무자(마케팅 본부장, 데이터팀 리드)가 읽었을 때 AI 가 쓴 티가 나는 문장. 번역투 표현, 상투적인 마무리나 교훈, 이미 한 말의 되풀이, 근거 없는 과장, 어색한 명사 나열, 정보 없는 군더더기, 앞뒤가 맞지 않는 접속 같은 것. 문체 취향 차이만 있는 문장은 넣지 않는다. 표 셀과 코드는 제외한다.
2. 정보 손실이나 사실 변경: `{SRC}` 에 있던 수치, 날짜, 비교 결과, 원인 설명, 계획, 결정, 한계 서술 중 `{DOC}` 에서 빠지거나 뜻이 바뀐 것. 표현만 바뀌고 뜻이 같은 것은 넣지 않는다.

출력은 아래 JSON 하나만. 설명 문장을 붙이지 않는다.

```json
{
  "ai_like": [{"quote": "DOC 에 있는 그대로 인용", "reason": "한 줄"}],
  "info_loss": [{"src_quote": "SRC 에 있던 내용 인용", "what": "빠짐 또는 어떻게 바뀜, 한 줄"}],
  "overall": "DOC 전체가 사람이 쓴 글로 읽히는 정도와 가장 눈에 띄는 버릇, 두 문장"
}
```
