# tone-fix

[![release](https://img.shields.io/github/v/release/bahamoth/tone-fix)](https://github.com/bahamoth/tone-fix/releases) ![license](https://img.shields.io/badge/license-MIT-blue)

한국어 문서, 인포그래픽, 강의자료, 슬라이드 덱, 보고서의 AI 말투와 번역체를 걷어내고, 구조를 세우고, 훑어 읽히게 만드는 스킬. [Agent Skills](https://agentskills.io) 표준을 따르는 `SKILL.md` 패키지이며, Claude Code 플러그인으로도 동작한다.

AI 가 쓴 한국어 문서는 첫 화면에서 드러난다. 제목이 질문으로 운을 떼고, 본문이 "저희"로 방어하고, 결론이 "A 가 아니라 B 다"로 힘을 준다.

어휘를 고쳐도 남는 문제가 있다. 요약이 본문의 압축본이고, 왜 이 글을 쓰는지가 없고, `L0~L5` 같은 코드가 정의 없이 돌아다니고, 문단이 7문장씩 이어진다.

단어를 다 고쳐도 남는 말투가 있다. 사실 뒤에 "이 전제가 설계를 결정한다" 를 붙이고, 리드에서 한 말을 문단 끝에서 "이것이 ~ 계약이다" 로 되풀이하고, source of truth 를 '진실 소스' 로 옮긴다. 같은 버릇이 문서마다 다른 단어로 나오므로 단어 목록으로는 막을 수 없다.

이 스킬은 그 신호를 규칙표로 정의하고 세 단계와 독립 판독으로 걷어낸다.

어휘, 패턴은 스캐너로, 문장, 구조는 판별법으로, 문맥은 판별 질문 여섯 개와 새 컨텍스트 판독자로, 가독성은 검출기로 교정한다. 어색한 핵심 문장은 낱말을 바꾸지 않고 취지를 뽑아 다시 짓는다. 기준은 교양 있는 실무자가 쓰는 보고서 문어다.

## 3단계 파이프라인

| 단계 | 성격 | 잡는 것 | 도구 | 통과 기준 |
|---|---|---|---|---|
| 1단계 패턴 스캔 | 결정론적 | 1인칭, 가정형, 상투 제목, 수사의문문, 본문 대시, `발화`, `~가 아니라`, `L0~L5`, `근거가 수렴`, `문제는 ~는 점이다`, `은퇴`, `더 잡는다`, `~은 셋이다`, `소음`, `원천`, `판단이 나온다`, `머릿속`, `—`, `·` 등 30종 | `scripts/check_lexical.py` | `hits: 0` |
| 2a단계 문장, 어휘 | 맥락 판단 | 미확정 단정, 동의어 중복, 의인화, 구어 어휘 | 규칙표 판별법 | 판별법 통과 |
| 2b단계 문단, 구조 | 맥락 판단 | 요약 훅, 문제제기 절, 단계 정의 표, 절 첫 문장, 목록 도입 명사구 | 규칙표 판별법 | 판별법 통과 |
| 2c단계 문맥 판독 | 맥락 판단 | 문어 격, 어울리지 않는 서술어, AI 조어, 분해와 재조립, 의의 꼬리, 지시어 재진술, 꼬리표 판정, 명사화 사슬, 직역 숙어, 과장, 일반론, 문장 간 논리, 반복 | `scripts/sentence_sheet.py` 판독표 + 판별 질문 | 문단 전부 판독 |
| 3단계 가독성 | 결정론적 + 판단 | 키프레임 공백, 문단 길이, 볼드 남발, 리드 뒤 줄바꿈, 문장 경계 `<br>` | `scripts/check_md_layout.py`, `scripts/check_br.py` | `violations: 0` |
| 마무리 독립 판독 | 맥락 판단 | 작성자가 못 보는 문맥 말투 | 새 컨텍스트 판독자 + `references/review-prompt.md` | 지적마다 수용 또는 기각 사유 기록 |

마지막에 원문과 작업 경위를 모르는 판독자가 산출물만 다시 읽고, 1단계와 3단계 스크립트를 다시 돌린다. 작성자는 자기 문장의 버릇을 잘 보지 못하고, 2, 3단계 재작성이 새 위반을 만들 수 있다.

## How It Checks

말투 교정을 감으로 끝내지 않는다. 결정론 단계는 스크립트 셋이 관문이고, 판단 단계는 판독표와 독립 판독자가 받친다.

- **`check_lexical.py`**: 어휘 신호 30종을 정규식으로 잡는다. `--honorific` 은 존대 문서에서 평어체 잔존을 추가로 잡는다.
- **`check_md_layout.py`**: MD 의 볼드 리드 프레임, 두 절 리드, 리드 뒤 같은 줄 부연, 요약 항목, 문제제기 절, 단계 정의, 목록 앞 개수 예고 문장, 키프레임 공백, 문단 길이, 볼드 남발을 잡고, `X는 Y다` 복사 구조 리드는 `advisories:` 로 따로 센다.
- **`check_br.py`**: HTML 좁은 블록과 `innerHTML` 주입 문자열에서 문장 경계 `<br>` 누락을 잡는다.
- **`sentence_sheet.py`**: 판독표를 만든다. 위반을 판정하지 않고, 문서를 문단(P), 문장(S) 번호로 펼쳐 빠짐없이 읽게 하고, 읽으면서 세기 어려운 것만 센다: 같은 평가어 3회 이상, 앞선 리드와 낱말이 겹치는 끝 문장, 판정형 어미 연속.
- **독립 판독**: 서브에이전트에게 산출물과 [`references/review-prompt.md`](references/review-prompt.md) 만 주고 판별 질문 여섯 개(삭제, 문어, 어울림, 역번역, 재진술, 근거)로 읽힌다. 지적은 문장 ID, 원문 인용, 판별 근거, 교정안, 확신으로 돌아오고, 작성자가 수용 또는 기각 사유를 보고에 남긴다.

모두 python3 표준 라이브러리만 쓴다. 스크립트 0건은 필요조건이다. 미확정 단정, 동의어 중복, 절 첫 문장, 문맥 기제 같은 판단 규칙은 판별 질문으로 확인하고 보고에 남긴다. 판독에서 여러 문서에 반복되는 표현이 나오면 결정론 규칙으로 올린다.

규칙은 실제 리뷰에서 나온 지적을 옮긴 것이다. 예: "발화라는 단어 금지. 전형적인 AI 표현.", "사람은 근거를 수렴한다고 표현하지 않는다.", "XX 가 답하는 질문은 XX 가지다 → 사람은 이런 표현을 안 써.", "소음이라는 직역보다는 노이즈가 자연스럽다."

## Usage

문서, 덱, 인포그래픽, 보고서를 작성, 마무리하는 단계에서 자동으로 활성화된다. 다음과 같은 요청으로도 트리거된다.

```
"이 문서 AI 말투 좀 고쳐줘"
"제목을 명사구로 바꿔줘"
"번역체 제거해줘"
"이 보고서 가독성 개선해줘"
```

수동 점검:


## Out of Scope

- 문장의 의미나 사실 내용을 바꾸지 않는다. 사실의 범위를 소스가 확인한 곳까지 좁힐 뿐이다.
- 맞춤법, 띄어쓰기 전반을 교정하는 도구가 아니다.
- 업계 표준 계층 용어(OSI L7, 알림 등급 L1/L2)와 통계의 수렴은 교정 대상이 아니다.
- 영어 인용문 안의 retired, kill 같은 원어 표현은 그대로 둔다.
- 한자어가 현장 어휘인 용어(임계, 기준선, 지출, 노출)는 외래어로 되돌리지 않는다.
