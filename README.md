# tone-fix

[![release](https://img.shields.io/github/v/release/bahamoth/tone-fix)](https://github.com/bahamoth/tone-fix/releases) ![license](https://img.shields.io/badge/license-MIT-blue)

한국어 문서·인포그래픽·강의자료·슬라이드 덱의 AI 말투와 번역체를 걷어내고 명사구 제목·사실 기반 어조로 교정하는 스킬. [Agent Skills](https://agentskills.io) 표준을 따르는 `SKILL.md` 패키지이며, Claude Code 플러그인으로도 동작한다.

AI 가 쓴 한국어 문서는 첫 화면에서 드러난다. 제목이 질문으로 운을 떼고, 본문이 "저희"로 방어하고, 결론이 "A 가 아니라 B 다"로 힘을 준다. 이 스킬은 그런 신호를 규칙 19절로 정의하고, grep 15종과 구조 검출기 1종으로 산출물에서 0건이 될 때까지 걷어낸다.

## What It Catches

규칙 19절을 독자 관점에서 다섯 갈래로 묶으면 다음과 같다.

| 갈래 | 신호 | 교정 | 규칙 |
|---|---|---|---|
| 제목·부제 | 왜 중요한가 / 한눈에 / ~란? / 이 덱의 구성 | 명사구로 대상·결론을 직접 명시: 중요성 · 구성 | §8, §8.1, §8.3 |
| 어조·주어 | 우리는 5/29 까지 해결합니다 | 차주(5/29) 해결 예정입니다 | §1, §2, §3, §6, §7 |
| 사실 범위 | 지연될 수 있습니다 / 곧 출시 / 그 외 ~도 ~한다 | 소스에 있는 사실까지만, 채우기 문구는 비움 | §4, §8.2, §8.4 |
| 어휘·번역투 | 캠페인을 띄운다 / 발화율 65% / 각각 따로따로 | 캠페인을 노출한다 / 트리거율 65% / 각각 | §8.3, §8.5, §8.6, §8.8, §8.9 |
| 레이아웃 | 좁은 카드에서 둘째 문장이 어절 중간에 꺾임 | 어절 단위 줄바꿈, 문장 경계 `<br>`, 명사구 꼬리는 ` · ` 연결 | §9, §9.1 |

## How It Checks

말투 교정을 감으로 끝내지 않는다. 세 층으로 점검하고 마지막 층이 0건이어야 마무리다.

1. **규칙표 치환.** 19절마다 ❌→✅ 대조표와 판별법이 있다. 예: 부제에서 고유명사·수치·구체 동작을 지워도 문장이 성립하면 빈 프레이밍이다.
2. **일괄 점검 grep 15종.** 1인칭·가정형·추측 단어·상투 제목·수사의문문 어미·메타 라벨·본문 대시·`발화`·`~가 아니라` 등 어휘 신호를 산출 파일에서 잡는다.
3. **§9.1 구조 검출기.** 어휘 grep 이 못 보는 줄바꿈 구조를 python3 스크립트로 검출한다. `<p>`·`<dd>`·`<li>`·`<small>` 과 `innerHTML` 로 주입되는 JS 문자열에서 문장 경계 `<br>` 누락을 잡아낸다. 의존성 없음, HTML 산출물 전용.

규칙은 실제 리뷰에서 나온 지적을 옮긴 것이다. §8.6~§8.9 네 절은 지적 문장을 그대로 인용해 두었다. 예: "발화라는 단어 금지. 전형적인 AI 표현."

## Usage

문서·덱·인포그래픽을 작성·마무리하는 단계에서 자동으로 활성화된다. 모든 한국어 문서 산출물의 마무리 관문으로 상시 동작한다. 다음과 같은 요청으로도 트리거된다.

```
"이 문서 AI 말투 좀 고쳐줘"
"제목을 명사구로 바꿔줘"
"번역체 제거해줘"
"이 문장 AI스러운데 톤 다듬어줘"
```

적용 절차는 세 단계다. 제목·부제·표 헤더를 먼저 훑고, 규칙표로 다시 쓰고, grep 과 검출기를 돌려 0건을 확인한다.

## Installation

### Claude Code 플러그인으로

```bash
claude plugin marketplace add bahamoth/cc-marketplace
claude plugin install tone-fix
```

또는 이 레포를 직접 추가:

```bash
claude plugin add bahamoth/tone-fix
```

### Agent Skill 로 (다른 에이전트)

에이전트의 스킬 디렉토리에 클론한다. 경로는 도구마다 다르다. Codex CLI 는 `~/.agents/skills/`(개인) 또는 `.agents/skills/`(프로젝트).

```bash
git clone https://github.com/bahamoth/tone-fix ~/.agents/skills/tone-fix
```

## Out of Scope

- 문장의 의미나 사실 내용을 바꾸지 않는다. 사실의 범위를 소스가 확인한 곳까지 좁힐 뿐이다.
- 맞춤법·띄어쓰기 전반을 교정하는 도구가 아니다.
- MD 산출물은 렌더러가 개행을 접으므로 §9.1 문장 경계 줄바꿈을 적용하지 않는다.
